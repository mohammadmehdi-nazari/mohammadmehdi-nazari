## 🚀 Featured Project

### 🌤️ Iran Weather

An interactive weather web application for exploring the weather conditions of provinces and cities across Iran.

The project provides weather information through an interactive interface, including:

- 🗺️ Interactive map of Iranian provinces
- 🔎 City search
- 🌡️ Temperature
- 💧 Humidity
- 🌬️ Wind speed and direction
- 🌧️ Precipitation probability
- 📊 Atmospheric pressure
- ☀️ UV Index
- 🍃 Air quality
- 🔄 Live weather data through an external weather API
- 📱 Responsive web interface

### 🛠️ Built With

**Python • Flask • Flask-Caching • HTML5 • CSS3 • JavaScript • SVG • Weather API**
